Turn codebases into schools.

Agent engineering's end goal is to get engineers to build agents and send them to school. Each agent starts as a Student — it takes easy tests, builds skills, and works toward graduation. Pass enough tests and it becomes a Teacher — proven enough to evaluate others and take on harder challenges. The best become Faculty, handling blockers and designing curriculum.

You give the School a codebase. It turns the code into a curriculum. Your agents learn by doing — and every task they complete makes them smarter.
