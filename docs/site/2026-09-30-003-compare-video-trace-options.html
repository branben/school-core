How to read these

Options 1 and 2 both end with a line proving the video arrived — that is the thing that cannot be recovered later. Option 1 is recommended only because it costs no new machinery; if submission latency is not something anyone looks at, Option 2's single entry is the cleaner artifact.

Option 3 is not a tidier version of Option 1. It is a trace for a video that never finished.
