## Dual-version empirical facts (all verified, 147 green in BOTH fastmcp 4.1.0 and 3.4.8)

1. **Field renames**: `Tool.inputSchema`→`input_schema`; `CallToolResult.isError`→`is_error`;
   content block `mimeType`→`mime_type`. Legacy aliases exist but emit
   `fastmcp._warnings.FastMCPDeprecationWarning` **on any access** (even reads); `mcp` has
   no `__version__`. Fix: `_compat.py` with `getattr_renamed(obj, modern, legacy, default)`
   using a `_MISSING` sentinel (an `or`-chain breaks when modern value is falsy, e.g.
   `is_error=False`, and warns). mcp 2.x normalizes HTTP status text: a 504 surfaces as
   "Server returned an error response" (no "504 Gateway Timeout").
2. **fastmcp 4.x client mode** (KEY DECISION): default `"auto"` probes `server/discover`
   and **silently drops server→client notifications** (`on_tools_changed`→`received=[]`).
   `mode="legacy"` restores pre-v4 behavior (notifications delivered). DECISION: default
   `mode="legacy"` when `FASTMCP_GE_4` so #1739 session auth + `on_tools_changed` survive.
   "mcp 2.x forces stateless rewrite" is FALSE — `test_stateful_mcp.py` (3 tests) passed
   unchanged under legacy + `-W error`.
3. **fastmcp 4.x Client surface**: `is_connected`/`list_tools`/`close` present;
   `_session_state`, `_connect`, `.tools` REMOVED; `__aenter__` reentrant (refcounts,
   restarts completed background task). `client.py::connect()` must branch: fastmcp<4 →
   explicit `_session_state.lock` + `_reset_session_state(full=True)`; >=4 → bare
   `__aenter__()`. Dropping 3.x reset breaks reconnect after HTTP 504. fastmcp 3.x
   `Client.__init__` has no `mode` param → `kwargs.pop("mode", None)` guard.
4. **OAuth transport**: mcp 2.x swapped httpx→**httpx2** (mirrors httpx: AsyncClient/
   MockTransport/Response/ConnectError). `httpx2.HTTPError` is NOT a subclass of
   `httpx.HTTPError` → `oauth.py::_discover_oauth_metadata` `except httpx.HTTPError` silently
   missed discovery failures (REAL BUG). Fix: catch tuple `(httpx.HTTPError,
   *((httpx2.HTTPError,) if httpx2 else ()))`; guard `import httpx2` w/ ImportError.
5. **OAuth callback_handler**: mcp 1.x expects `tuple(code, state)`; mcp 2.x expects
   `mcp.shared.auth.AuthorizationCodeResult` (code/state/iss). Cross-version test stub:
   object with `.code/.state/.iss` (iss=None) + `__iter__` yielding (code, state). NOTE:
   nested-class class-body `code = code` is a NameError → assign in `__init__`.
6. **progressive_server fixture**: request-scoped `get_context().send_notification()` is
   DROPPED under mcp 2.x → use a server-level notification delivery path.
7. **Dual-version compatibility required**: SDK pin stays `fastmcp>=3.2.0,<4` until #5152;
   draft pins `<5`; tests must pass in BOTH (u2venv=4.1.0/2.3.0, mcp3venv=3.4.8/mcp1.x).
   Need `pytest-asyncio`+`anyio` in the 3.x venv (Python 3.13 → pytest needs plugin for
   `@pytest.mark.asyncio`).
