# Agent School Pipeline Summary
- **Student**: Takes the task and produces a candidate solution.
- **CTO Review**: Checks correctness and security of the solution.
- **COO Review**: Checks completeness and whether all requirements were met.
- **Bookbag**: Persists the reviewed work with its verdicts and scores.
- **AgentMail Card**: Delivers the reviewed work to the inbox for human approval via /approve, /reject, or /fix.
