The Nine Gates

Gate 1: CONTEXT ✅

Tooling: envit CLI

Verification: envit sync → .envit/AGENTS.md generated

Gate 2: PLAN ✅

Tooling: plannotator setup-goal, effective-html, tot

Verification: Goal package + HTML plan + shareable URL

Gate 3: REPRO

Tooling: Serena MCP, systematic-debugging

Verification: Failing test that captures the bug

Gate 4: TDD

Tooling: pytest, playwright

Verification: All tests green after fix

Gate 5: PRE-COMMIT

Tooling: requesting-code-review, rg

Verification: Zero lint/type findings

Gate 6: REVIEW

Tooling: plannotator guide export

Verification: Portable HTML review guide

Gate 7: VISUAL

Tooling: effective-html, Computer Use

Verification: Prototype + screenshot diffs

Gate 8: KPI

Tooling: effective-html reports

Verification: HTML report with bar charts

Gate 9: AUDIT

Tooling: thermo-nuclear-code-quality-review

Verification: Zero high-severity findings

Execution Rules

  • No skip: Every gate must pass before proceeding
  • Parallel safe: REPRO + VISUAL + KPI can run simultaneously
  • Fail fast: Gate fails → stop, fix, restart from that gate
  • Evidence: Every gate produces a verifiable artifact
