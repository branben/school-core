# School-Core Complete

Make one operator-controlled school-core deployment complete a trusted, reviewable issue-to-PR learning cycle across configured repository targets. Student coding must run in a disposable VM with no host fallback; the exact candidate must pass school-controlled verification, and PR creation must follow the configured human-approval policy. Merge remains human-controlled.

Shared understanding: [`facts.md`](facts.md). Execution plan: [`plan.md`](plan.md).

## Done condition

All accepted facts in `facts.md` have current implementation and verification evidence. A clean-environment rehearsal demonstrates issue intake through isolated execution, trusted candidate verification, durable teacher decision, same-repository source-code PR, learning/evidence persistence, and successful teardown; a second repository completes the flow through configuration alone. Injected failures prove fail-closed execution, safe publication reconciliation, durable recovery, and no duplicate PRs. Hosted setup, access, resource controls, and recovery are documented and verified. No candidate is automatically merged.
